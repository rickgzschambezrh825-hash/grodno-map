# 🗺️ ГИС «ПОИСК-ГРОДНО 1941/1944»

**Военно-картографический геопортал и база данных увековечения памяти погибших советских воинов (Гродненский район, 1941 / 1944 гг.)**

🌐 **Онлайн-версия:** [https://rickgzschambezrh825-hash.github.io/grodno-map/](https://rickgzschambezrh825-hash.github.io/grodno-map/)

---

## 📌 Основные возможности

* **Интерактивная карта** — визуализация оборонительных боев июня 1941 г. (68-й УР, 86-й Августовский ПО, контрудар 11-го мехкорпуса) и освобождения июля 1944 г. (операция «Багратион», 31-я и 50-я армии, 2-й гв. кавкорпус).
* **Сплит-экран «Было / Стало»** — синхронное визуальное сопоставление современных спутниковых карт с историческими топографическими картами РККА и немецкими картами Messtischblatt.
* **Реестр поисковых зон (GRO-Registry)** — координаты и архивные обоснования перспективных неучтенных санитарных захоронений.
* **Полевая навигация и GPS** — автономный компас, ведение по азимуту к целям, экспорт и импорт в форматах GPX и KML для мобильных навигаторов (OsmAnd, Garmin, Locus Map).
* **PWA & Офлайн-режим** — возможность установки приложения на мобильный телефон с кешированием данных при отсутствии связи в лесу.

---

## 📂 Структура проекта

* `index.html` — пользовательский интерфейс веб-приложения.
* `index.css` — тактическая темная тема (Glassmorphism, High-contrast).
* `app.js` — картографическое ядро и интерактивная логика.
* `data/history-data.js` — структурированная база данных воинов, объектов, выписок ЦАМО и точек поиска.
* `data/gpx-kml-utils.js` — модуль генерации треков и точек GPX/KML.
* `sw.js` & `manifest.json` — обеспечение автономного офлайн-режима.
