# Результаты исследований по поиску пропавших без вести воинов в Гродненском районе (1941, 1944 гг.)

В данной директории содержатся материалы комплексного военно-мемориального исследования, проведенного на основе плана [RESEARCH_PLAN.md](file:///c:/Users/john/Documents/antigravity/map/RESEARCH_PLAN.md).

## Структура файлов исследований:

1. **[01_1941_defense_grodno.md](file:///c:/Users/john/Documents/antigravity/map/research_data/01_1941_defense_grodno.md)** — Историческая реконструкция приграничных боев 1941 года (68-й УР, 86-й Августовский ПО, 11-й мехкорпус, 56-я и 85-я сд, фонды ЦАМО и NARA T-314).
2. **[02_1944_liberation_neman.md](file:///c:/Users/john/Documents/antigravity/map/research_data/02_1944_liberation_neman.md)** — Реконструирование боев июля 1944 года (операция «Багратион», форсирование Немана 31-й и 50-й армиями, 2-й гв. кавкорпус, плацдармы Пышки и Солы).
3. **[03_pow_and_archival_methodology.md](file:///c:/Users/john/Documents/antigravity/map/research_data/03_pow_and_archival_methodology.md)** — Методология работы с персональными карточками военнопленных (PK I, PK III), ПФД, центрами Дрезден/Арользен и алгоритмами поиска по родственникам для обхода писарских искажений.
4. **[04_gro_registry_geospatial.md](file:///c:/Users/john/Documents/antigravity/map/research_data/04_gro_registry_geospatial.md)** — Геоинформационный реестр поисковых точек (GRO-Registry), привязка к немецким аэрофотоснимкам Luftwaffe (NARA RG-373) и рекомендации по полевым работам.
5. **[05_sources_bibliography.md](file:///c:/Users/john/Documents/antigravity/map/research_data/05_sources_bibliography.md)** — Библиографический реестр и источниковедческий обзор боев в Гродненском районе с подробным разбором работ Д. Лютика, свидетельств А. Д. Шмелева и трудов по фортификации К. В. Шмелева.
