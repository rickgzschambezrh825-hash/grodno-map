# Локальная библиотека открытых источников по боям в Гродненском районе (1941, 1944 гг.)

В данной папке собраны и систематизированы выгруженные материалы, исследовательские тексты, мемуарные первоисточники и архивные выписки из открытого доступа, посвященные обороне 68-го УР, 86-го Августовского погранотряда, 56-й и 85-й сд в июне 1941 г. и освобождению Гродно в июле 1944 г.
